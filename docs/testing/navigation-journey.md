# Navigation release quick check

Use TestFlight 0.1.0 (19), available in Hackathon Internal. This guide supports physical-device acceptance and does not claim it is complete.

## Everyday navigation

- Switch between Chat, Map, Memories and Friends with the bottom tabs. Each destination retains its previous browsing position.
- Back returns one level. The house icon on detail screens returns directly to the Chat home.
- Question, observation and photo drafts survive detours. An unsent question can resume camera or voice entry. Restoring an existing answer does not start hidden recording.
- Use the share icon at the top of a memory to open its preview. Back returns to the memory.

## Jacky's continuous journey

Prepare once: enable friendships and map sharing in Family settings, then establish an accepted friendship through the friend codes. Use ordinary exploration cards for map and friend sharing. Private demo content stays isolated. The other tester also needs a shareable card.

1. Choose a question on Chat home, read or listen to the answer, add an observation and make a card. Answer correctly to reveal it.
2. Continue from the new card to map sharing. If no place was saved, explicitly choose the current area and allow location when requested.
3. After publication succeeds, continue to nearby adventures, open an event and choose sharing with a friend.
4. Select an accepted friend and send. The event invitation in the conversation opens the event again.
5. Open the friend's profile, choose a recent discovery and offer an exchange.
6. The other tester accepts. Refresh exchanges and open the received card. Use the house icon from any detail screen to return home.

## Recall and recovery

- Open discovery reminders from Map to revisit earlier discoveries. Reviewing an earned card does not award another one.
- Reminders start disabled and can be enabled or disabled explicitly. Opening a reminder returns to its original question.
- Test an unfinished question across a tab detour and a relaunch, including its observation and photo.
- Try pause, replay, maximum text and your preferred interface language.
- Complete physical microphone, camera, headphone switching, background interruption and actual notification-delivery checks.
